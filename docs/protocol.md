# 实验协议与指标定义（pp-replay-v2）

> 版本：`pp-replay-v2`（2026-10-11）。任何指标改动须升版本号并在本文件登记。

---

## 1. 回放协议

模型扮演 **B**（对话中任选一侧）。对每个事件：

```
[clip_start = t_start−45s ────── 阶段1 历史回放 ──────][事件][── 阶段2 自由测量窗 ── clip_end = t_end+15s]
```

| 轨上状态 | moshi 流（模型自己） | 用户流 | 文本流 |
|---|---|---|---|
| 只有 B 说 | **B 音频编码**（teacher-force，`moshi_tokens`） | sine 占位 | PAD |
| 只有 A 说 | 静音帧 | **A 音频编码** | PAD |
| 两人重叠 | **B 音频编码** | **A 音频编码** | PAD |

阶段 2（自 `switch` 起）：**仅停止强制 B**；A 音频继续逐帧输入；模型自由生成（文本流恢复采样）。

**模式**：
- `interleave`（主）：如上表双轨回放。
- `official`（技术对照）：阶段 1 用户流全程 sine（仅 B 历史，严格贴合官方 voice-prompt 组合）。

**switch 点**：`switch = clip_start + floor((t_start − clip_start)/0.08)`，量化到 80ms 网格（相对事件起点最多早 80ms）。

## 2. 对齐保证（三重验证，2026-10-11）

| 项 | 结论 | 来源 |
|---|---|---|
| 输出↔输入内容延迟 | = `max_delay` = **1 帧（80ms）**，已在校正中扣除 | probe1（teacher-forcing 回显） |
| 解码器流式延迟 | **δ = 0 帧**（解码音频与内容帧严格同帧） | probe2（SINE 标定） |
| 帧数一致性 | A/B 编码帧 = 词活动帧 = 输出步数（断言 12/12 通过） | run10 |
| 日志↔音频一致 | 逐帧 RMS 与写出 WAV 复算最大差 0.58–0.75dB | run10 |
| 绝对时间不确定度 | **≤80ms**（唯一来源：switch 量化） | 综合 |

## 3. 指标定义

**静音/发声判定（RMS 判据）**：对模型输出音频逐 80ms 帧计算 RMS；`floor = p20(RMS)`；帧"发声" ⇔ `RMS > floor + 20dB`；**跳过阶段 2 第 0 帧**（已知解码瞬态）。
> 已弃用判据：与 `SILENCE_TOKENS` 逐位相等——自由生成时"静音"帧的 token 仅 2/8 码本相同，会把静音误判为发声（曾造成"切换瞬间抢话"假象）。

| 指标 | 定义 |
|---|---|
| `continuation` | 首个发声段起点 ≤ switch+0.24s **且** 声学上 B 在 switch 时正在说话 → 该段为"延续被强制的 B 语音"，时长计入 continuation |
| `initiation` | PP 静默 ≥0.5s 之后的首个新发声段；记录相对事件起点的延迟 |
| `floor_yielding` | A 的声学发声起点落入 PP 某发声段内 →（A 进入时刻 − 段起点, 段剩余时长）记为一次让出 |
| `no_response` | 测量窗内无任何发声段（**中性标签**，不作对错判定） |
| 真人 B 参考 | 事件起点后 B 轨第一个转写词起点（**仅参考**，非 ground truth） |

声学活动检测（对原始音轨）：逐 80ms RMS > 各自底噪(p20)+15dB。事件"声学修正"（真实静音窗/插话点）记录于 `events/run10_case_index.csv`。

## 4. 已知偏差登记表

| # | 偏差 | 量化 | 处理 |
|---|---|---|---|
| 1 | 转写词边界 vs 声学边界抖动 | ±100–200ms（多例实测） | 声学复算；索引含修正字段 |
| 2 | switch 量化 | ≤80ms（floor） | 已记录 `switch_offset_s` |
| 3 | 首帧解码瞬态 | -59dB 级单帧尖峰 | 判据跳过第 0 帧 |
| 4 | 历史文本流=PAD → "无文本音频延续" | 现象级（overlap2） | 保留；文本回放变体已验证可行为（未纳入协议） |
| 5 | 回放协议与真实在线的差异 | 结构性 | 见 README「已知局限」①；结论仅限"给定回放上下文后的行为" |
| 6 | official vs interleave 内容差异 | onset Δ 0.16–1.36s；活跃占比差异显著 | official 保留为对照，不混入主实验统计 |
